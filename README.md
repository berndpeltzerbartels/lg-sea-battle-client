# LG Sea Battle

Small Babylon.js prototype for a 3D boat scene on open water.

## Run

```sh
npm install
npm run dev
```

Open `http://localhost:5173/`.

## Controls

- Up arrow: accelerate
- Down arrow: reverse / slow down
- Left arrow: turn left
- Right arrow: turn right

The boat uses smoothed acceleration, drag, turn velocity, camera follow, and a small wave bob so movement feels gradual instead of jerky.

## Crew Kill Stream Regression

First run `./gradlew test --tests '*CrewKillBrowserFixtureTest'` in the adjacent
`server` checkout. This generates before/after snapshots from actual cannon and
flak collisions, including the server's sinking and alias changes.

With the client dev server running, run:

```sh
SEA_BATTLE_BASE_URL=http://127.0.0.1:5182 npx playwright test tests/e2e/crew-kill-stream.spec.js --workers=1
```

The browser test replays those serialized snapshots through the normal game-stream
handler for bridge and gunner stations. Login and network transport are mocked;
the collision results are generated by the real server simulation.
